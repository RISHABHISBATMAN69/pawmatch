# PawMatch

PawMatch is a pet adoption matching prototype. It helps adopters compare animals against their home, schedule, experience, household, and care budget, while showing each animal's personality and care needs.

## Features

- Lifestyle-based matching for dogs, cats, rabbits, birds, and small pets.
- Pet profiles with temperament, health information, home requirements, and day-to-day care notes.
- Match sorting, saved-pet toggles, and adoption-interest prompts.
- A shelter profile form for drafting an animal listing.
- Responsive, single-page interface with no build step or package dependencies.


## Prototype notes

Animal listings and match scores are sample data intended to demonstrate the experience. Saving pets, expressing interest, and creating shelter profiles do not contact a shelter or persist to a backend; feedback is kept in the current browser session.
